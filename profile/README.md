# SPD Upgrade Tool - Flash a Unisoc PAC Package

## At a Glance

Spreadtrum and Unisoc phones are serviced with a PAC file and this upgrade tool, or with ResearchDownload when the job is a lower-level research image. Upgrade is the narrower window: load the package, connect the phone, start. You use the PAC the vendor or the official channel named for the handset on the bench.

- One PAC for this model
- Download mode and the Unisoc driver
- A battery that lasts the upgrade
- User data treated as gone unless the package truly preserves it
- No mixing of PAC files from two similar marketing names

Read the project name inside the tool after the PAC loads. If it is not this phone, unload it.

## Package Check

| Check | Pass |
|---|---|
| File opens in the tool | It is a PAC, not a zip of unrelated images |
| Project name | Matches the model you are holding |
| Port | Appears only after the phone is in download mode |
| Size | A tiny PAC is an unfinished download |
| Result line | Success before you unplug |

1. Install the SPD driver.
2. Load the PAC and read the project name.
3. Put the phone into download mode.
4. Start and wait.
5. Boot once and confirm the build.
6. If it fails, repeat this PAC once. Do not swap in a research image you do not understand.

## Fits

Unisoc phones you may update with an official PAC. A poor fit for MediaTek and Qualcomm. A poor fit for pulling photos off a working phone. If it boots, copy the photos before an upgrade.

## Fixes

No port. Driver or mode. Reinstall the driver and redo the key combo.
PAC will not load. The file is corrupt. Download it again.
Upgrade stops. Leave the cable. If it already failed, rerun the same PAC.
Wrong language or modem. The PAC was another region's twin model.
The phone is not yours to unlock. This tool is a firmware writer, not an account tool.

## Project Name, Then the Port

Load the PAC before the phone is in a hurry. Read the project name inside SPD Upgrade Tool. If it is not this Unisoc model, unload the file. A similar marketing name often hides a different radio. A tiny PAC is an unfinished download. Open it in the tool or fetch it again. Do not start an upgrade against a blank port.

Download mode and the Unisoc driver have to exist first. Repeat the same PAC once if the write stops. Do not switch to a research image you have not read. User data should be treated as gone unless this package truly keeps it. Copy photos while the phone still boots. MediaTek and Qualcomm phones do not belong in this window.

- PAC opens and shows a project name
- Name matches the handset
- Port appears only in download mode
- Same file retried once
- Photos copied first
- Research tools not mixed in as a second guess
- Battery charged

| Failure | Check |
|---|---|
| No port | Driver or key combo |
| PAC will not load | Corrupt file |
| Wrong language or modem | Another model's package |
| Stops midway | Cable, then the same PAC |

The upgrade writes storage. It does not unlock an account.
